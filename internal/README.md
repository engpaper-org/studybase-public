# Internal Pages

This folder is for HTML documents loaded by scripts or iframes, not primary public navigation.

- `iframes/`: loading and transition documents used inside resource viewer iframes.
- `get_help/`: standalone mental-health check-in iframe variants under development.
- `alerts/`: alert and announcement documents loaded by scripts.
- `apg/`: private APG request screens loaded by APG scripts.
- `myaccount/`: account-only embedded documents that are not public route pages.
- `safety/`: AutoSafe utility pages and generated safety-reference views.
- `system/`: protected-resource notice pages selected from backend state codes.

If an internal page moves, update the script that embeds it at the same time.
