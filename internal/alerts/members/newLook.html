New Look

A better menu and more features when using a material

We’ve updated the material experience to make it feel cleaner, easier to use, and more useful while you browse content.

Members will now see a refreshed menu experience when opening materials, giving quicker access to useful actions without getting in the way of the content itself.

Alongside the updated look, the material view now supports more features to improve navigation, control, and overall usability while studying.

The aim is to make working through resources feel more polished and more practical, especially during longer revision sessions.

What’s improved

Better menu

A more refined menu layout makes important actions easier to reach.

More features

Extra controls and options are now available when viewing a material.

Cleaner layout

The experience is more organised and less cluttered while staying powerful.

Better study flow

It should now feel smoother moving between actions while staying focused on the resource.
