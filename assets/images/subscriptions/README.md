# Subscription cover art

Add cover images here as JPG files using a **16:9 aspect ratio**.

Recommended export size: **1600 x 900 pixels**. The UI preserves 16:9 and uses `object-fit: cover`, so important text or faces should stay away from the outer edges.

Required filenames:

- `leaderboards-plus.jpg`
- `proxy-plus.jpg`
- `music-plus.jpg`
- `chat-plus.jpg`
- `custom-domain.jpg`
- `all-access.jpg`
- `all-access-domain.jpg`
- `ai-credit-pack.jpg`

Until a file is added, its card displays the built-in gradient fallback.
