# RevisionBase Logo Slots

Drop your final logo files here using these names and the site will pick them up from the shared navigation and footer patterns:

- `navbar.png` - square or softly rounded app icon used in the global navbar and past-paper preview cards.
- `main.ico` - favicon/browser tab icon.
- `brand-header.png` - optional wide header logo for future hero/header placements.
- `brand-mark.png` - optional icon-only transparent PNG for compact UI.
- `og-cover.png` - optional 1200x630 social preview image.

Current pages still use `navbar.png` and `main.ico` as placeholders, so replacing those two gives you the biggest visible rebrand immediately.
