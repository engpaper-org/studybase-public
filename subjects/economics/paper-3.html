Economics Paper 3

Paper 3 is synoptic. You must combine micro and macro ideas and evaluate policies using data.

Focus

Synoptic analysis and data response.

Question style

Data interpretation and long essays.

Top mark signal

Balanced evaluation with evidence.

Checklist

Paper 3 topic checklist

  • Linking micro and macro concepts
  • Interpreting data in context
  • Evaluating policy effectiveness
  • Global trade and interdependence
  • Market failure in a macro context
  • Judgement with evidence

Exam technique

  • Use data to support every evaluation point
  • Blend micro and macro diagrams
  • Explain short and long term effects
  • Use comparative language in conclusions
  • Finish with a clear judgement

Common errors

  • Ignoring the data in a response
  • Using only micro or only macro analysis
  • No evaluation or judgement
  • Diagrams without explanations
  • Confusing causal direction

Practice set

  • Explain how a policy affects consumers and producers.
  • Analyse a data set and suggest two conclusions.
  • Evaluate a trade policy using a diagram.
  • Write a conclusion with judgement and evidence.
