Exam skills for top marks

  • Use precise biological terms in every explanation
  • Link structure to function in full sentences
  • Explain processes step by step, no skipping
  • Quote data points when evaluating experiments
  • Balance equations and include units

Common pitfalls to avoid

  • Confusing diffusion, osmosis, and active transport
  • Skipping keywords like activate, inhibit, or regulate
  • Ignoring data when asked to evaluate
  • Forgetting to label axes on graphs
  • Vague statements without scientific evidence

Quick practice

10 minute drills

Build accuracy before tackling a full paper.

Track papers
  • Explain how enzyme activity changes with temperature using a graph.
  • Describe how a mutation can alter protein structure and function.
  • Interpret a data set on photosynthesis rate and draw conclusions.
  • Plan a practical to test membrane permeability.
  • Write a short evaluation of an experiment with two improvements.
  • Summarise a feedback loop in four sentences.
