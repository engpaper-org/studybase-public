Paper 3 targets practical skills and synoptic connections. The strongest answers use data to justify every claim.

Focus

Required practical techniques and analysis.

Question style

Methods, evaluation, and data response.

Top mark signal

Quantitative evaluation and clear conclusions.

Checklist

Paper 3 topic checklist

  • Required practicals and apparatus use
  • Titration, reflux, distillation, and chromatography
  • Data processing and calculation skills
  • Uncertainty, precision, and accuracy
  • Evaluation and improvements
  • Synoptic links across physical and organic topics

Exam technique

  • Quote data when evaluating practicals
  • Explain sources of error with evidence
  • Write clear method steps and controls
  • Use correct significant figures
  • Link results to theory and equations

Common errors

  • Evaluation without referencing data
  • Confusing accuracy with precision
  • Missing control variables
  • Ignoring measurement uncertainty
  • Forgetting to link back to the question

Practice set

  • Write a method for an enthalpy change experiment.
  • Evaluate a titration data table using two points.
  • Suggest improvements to increase accuracy.
  • Interpret chromatography results with calculations.
