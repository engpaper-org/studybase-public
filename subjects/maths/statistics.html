Statistics

Statistics is about interpreting data and making conclusions with evidence. Precision and clear wording matter just as much as calculations.

Focus

Probability, distributions, hypothesis tests, data presentation.

Question style

Interpretation, calculations, and written conclusions.

Top mark signal

Clear hypotheses, correct tail, and context in conclusions.

Checklist

Statistics topic checklist

  • Sampling methods and data presentation
  • Measures of location and spread
  • Probability rules and tree diagrams
  • Binomial and normal distributions
  • Correlation, regression, and interpretation
  • Hypothesis testing and critical regions
  • Statistical tests and conclusions in context

Exam technique

  • Define null and alternative hypotheses clearly
  • State the significance level before testing
  • Show distribution parameters and conditions
  • Use correct tail and justify your choice
  • Write conclusions in context of the data

Common errors

  • Using the wrong tail in hypothesis tests
  • Rounding too early and losing accuracy
  • Misreading critical values from tables
  • Failing to state assumptions or conditions
  • Conclusions without reference to context

Practice set

  • Carry out a binomial probability question with justification.
  • Use a normal approximation with continuity correction.
  • Interpret a regression line and comment on correlation.
  • Complete a hypothesis test and write the conclusion.
