Exam skills for top marks

  • Write equations first, then substitute values
  • Keep track of units and convert early
  • Explain assumptions behind your model
  • Use vector directions and sign conventions
  • Quote data in evaluation questions

Common pitfalls to avoid

  • Ignoring significant figures
  • Mixing up scalar and vector quantities
  • Using formulas without stating variables
  • Not explaining results in context
  • Forgetting to account for uncertainty
