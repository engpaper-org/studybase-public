Custom playlist setup

Use this guide to make a public playlist endpoint that the music app can open. The playlist URL must be public, must not need login, and must return a simple list of songs.

View playlist format Copy Worker code

Before you start

The music player needs one public playlist URL. For Cloudflare, that URL should be a Worker connected to an R2 bucket. For GitHub Pages, use a custom domain because default GitHub domains may be blocked.

Audio filesUpload MP3, M4A, WAV, OGG, FLAC, or AAC files. Keep names consistent.
Cover imageFor Cloudflare, upload a cover image called cover at the bucket root. The Worker example below will find common image extensions.
No loginCustom playlist endpoints should be public. They do not use the music app device-code authentication.

Cloudflare Worker + R2

This option gives you one public playlist URL. Put the songs in a bucket folder called music/, put the cover image at the root of the bucket as cover.jpg, cover.png, cover.webp, or cover.gif, then connect that bucket to a Worker named MUSIC_BUCKET.

  1. Open the Cloudflare dashboard and choose Workers & Pages. Watch help
  2. Create a Worker. This is the public URL the music app will check when you add the custom playlist.
  3. Open R2 Object Storage, create a bucket, and upload your audio files into a folder named music/. R2 video
  4. Upload your cover image at the bucket root, not inside music/. Name it cover with an image extension such as cover.jpg or cover.png.
  5. Open the Worker settings, go to bindings, add an R2 bucket binding, choose your bucket, and set the variable name to MUSIC_BUCKET. Binding video
  6. Paste the Worker code below into the Worker editor, then deploy it.
  7. Open the Worker URL in your browser. You should see JSON with a playlist name, cover URL, and tracks list. If it shows an error, read the message and fix that Cloudflare setting first.
  8. Paste the Worker URL into the music app and choose Cloudflare Worker + R2 as the provider.

Cloudflare Worker code

This example does everything needed for a simple custom playlist: it lists audio files in R2, finds a cover image called cover, returns playlist JSON, and streams the files publicly through the Worker.

Set your R2 bucket binding name to MUSIC_BUCKET. Upload songs into the folder named in PLAYLIST_PREFIX. Upload the cover image at the root of the bucket as cover.jpg, cover.png, cover.webp, or cover.gif.
const PLAYLIST_NAME = "My custom playlist";
const PLAYLIST_PREFIX = "music/";
const AUDIO_EXTENSIONS = new Set([".mp3", ".m4a", ".wav", ".ogg", ".flac", ".aac"]);
const COVER_EXTENSIONS = [".jpg", ".jpeg", ".png", ".webp", ".gif"];

function corsHeaders(request) {
  return {
    "Access-Control-Allow-Origin": "*",
    "Access-Control-Allow-Methods": "GET, HEAD, POST, OPTIONS",
    "Access-Control-Allow-Headers": request.headers.get("Access-Control-Request-Headers") || "Range, Content-Type, Authorization, X-Playlist-Token",
    "Access-Control-Max-Age": "86400",
    "Vary": "Origin, Access-Control-Request-Headers"
  };
}

export default {
  async fetch(request, env) {
    const headers = corsHeaders(request);

    if (request.method === "OPTIONS") {
      return new Response(null, { status: 204, headers });
    }

    try {
      const url = new URL(request.url);

      if (url.pathname.startsWith("/file/")) {
        return streamFile(request, env, decodeURIComponent(url.pathname.slice("/file/".length)), headers);
      }

      return playlistResponse(request, env, headers);
    } catch (error) {
      return json({
        ok: false,
        error: "Playlist setup problem",
        message: error.message || "The playlist Worker could not finish the request.",
        fix: "Check that the R2 binding is named MUSIC_BUCKET and that PLAYLIST_PREFIX matches the folder containing your music."
      }, headers, 500);
    }
  }
};

async function playlistResponse(request, env, headers) {
  if (!env.MUSIC_BUCKET) {
    return json({
      ok: false,
      error: "Missing R2 binding",
      message: "This Worker cannot see an R2 bucket binding called MUSIC_BUCKET.",
      fix: "In Cloudflare, open the Worker settings, add an R2 bucket binding, set the variable name to MUSIC_BUCKET, then deploy again."
    }, headers, 500);
  }

  const origin = new URL(request.url).origin;
  const objects = [];
  let cursor;

  do {
    const page = await env.MUSIC_BUCKET.list({
      prefix: PLAYLIST_PREFIX,
      cursor,
      limit: 1000
    });
    objects.push(...page.objects);
    cursor = page.truncated ? page.cursor : undefined;
  } while (cursor);

  if (!objects.length) {
    return json({
      ok: false,
      error: "No files found",
      message: "The R2 bucket was reached, but no files were found inside the folder set by PLAYLIST_PREFIX.",
      fix: "Upload your songs into the folder named " + PLAYLIST_PREFIX + ", or change PLAYLIST_PREFIX at the top of the Worker code to match your folder."
    }, headers, 500);
  }

  const coverKey = await findCoverKey(env);

  const tracks = objects
    .filter((item) => AUDIO_EXTENSIONS.has(extensionOf(item.key)))
    .map((item) => {
      const fileName = item.key.slice(PLAYLIST_PREFIX.length);
      return {
        fileName,
        url: origin + "/file/" + encodeURIComponent(item.key)
      };
    });

  if (!tracks.length) {
    return json({
      ok: false,
      error: "No audio files found",
      message: "The folder was found, but it does not contain any supported audio files.",
      fix: "Upload .mp3, .m4a, .wav, .ogg, .flac, or .aac files into " + PLAYLIST_PREFIX + "."
    }, headers, 500);
  }

  return json({
    ok: true,
    name: PLAYLIST_NAME,
    coverUrl: coverKey ? origin + "/file/" + encodeURIComponent(coverKey) : "",
    tracks
  }, headers);
}

async function streamFile(request, env, key, cors) {
  if (!env.MUSIC_BUCKET) {
    return json({
      ok: false,
      error: "Missing R2 binding",
      message: "This Worker cannot stream files because MUSIC_BUCKET is not connected.",
      fix: "Add an R2 bucket binding named MUSIC_BUCKET in the Worker settings."
    }, cors, 500);
  }

  if (!key || key.includes("..")) {
    return json({
      ok: false,
      error: "Invalid file path",
      message: "The file URL is missing or invalid.",
      fix: "Use the song URLs returned by the playlist JSON instead of typing file URLs manually."
    }, cors, 404);
  }

  const object = await env.MUSIC_BUCKET.get(key);
  if (!object) {
    return json({
      ok: false,
      error: "File not found",
      message: "The file was not found in R2: " + key,
      fix: "Check that the file still exists in the bucket and that the file name has not changed."
    }, cors, 404);
  }

  const headers = new Headers(cors);
  object.writeHttpMetadata(headers);
  headers.set("Cache-Control", "public, max-age=3600");
  headers.set("Accept-Ranges", "bytes");

  if (!headers.get("Content-Type")) {
    headers.set("Content-Type", contentTypeForKey(key));
  }

  return new Response(request.method === "HEAD" ? null : object.body, { headers });
}

function json(payload, cors, status = 200) {
  return new Response(JSON.stringify(payload), {
    status,
    headers: {
      ...Object.fromEntries(new Headers(cors)),
      "Content-Type": "application/json; charset=utf-8",
      "Cache-Control": "public, max-age=60"
    }
  });
}

function extensionOf(key) {
  const dot = key.lastIndexOf(".");
  return dot === -1 ? "" : key.slice(dot).toLowerCase();
}

function contentTypeForKey(key) {
  const ext = extensionOf(key);
  if (ext === ".mp3") return "audio/mpeg";
  if (ext === ".m4a" || ext === ".aac") return "audio/aac";
  if (ext === ".ogg") return "audio/ogg";
  if (ext === ".wav") return "audio/wav";
  if (ext === ".flac") return "audio/flac";
  if (ext === ".jpg" || ext === ".jpeg") return "image/jpeg";
  if (ext === ".png") return "image/png";
  if (ext === ".webp") return "image/webp";
  if (ext === ".gif") return "image/gif";
  return "application/octet-stream";
}

async function findCoverKey(env) {
  for (const ext of COVER_EXTENSIONS) {
    const key = "cover" + ext;
    const object = await env.MUSIC_BUCKET.head(key);
    if (object) return key;
  }
  return "";
}
  1. In Cloudflare, create an R2 bucket and upload your songs into the music/ folder.
  2. Upload one image named cover.jpg, cover.png, cover.webp, or cover.gif at the root of the bucket, not inside the music/ folder.
  3. Create a Worker and paste the code above.
  4. Add an R2 bucket binding named MUSIC_BUCKET. Watch help
  5. Deploy the Worker and copy the Worker URL into the music app.

Other public URL

Any service can work if it gives you a public HTTPS URL that returns JSON and allows the music app to fetch it from the browser.

  1. Upload your music somewhere public.
  2. Create a JSON playlist file using the format below. JSON video
  3. Make sure the URL starts with https://.
  4. Make sure the service allows browser requests from StudyBase. This is usually called CORS.
  5. Paste the public JSON URL into the music app.

Playlist format

The music app accepts either a plain array of audio URLs or an object with a playlist name, cover URL, and tracks. The object format is better because it can show a cover.

{
  "name": "My playlist",
  "coverUrl": "https://example.com/cover.jpg",
  "tracks": [
    {
      "url": "https://example.com/music/Artist -- Song.mp3",
      "fileName": "Artist -- Song.mp3"
    }
  ]
}

If you do not send a coverUrl, the app uses /assets/images/m-covers/default.jpg. When adding the playlist, choose the song name format that matches your files. The default is Show full file name.

Song name formats

Pick the option that matches how your files are named. Keep the same style for every song in the playlist.

  1. Show full file name: displays the whole file name exactly as it comes from your playlist.
  2. {artist} -- {name}: turns Offset -- Ric Flair Drip.mp3 into artist Offset and title Ric Flair Drip.
  3. {name} -- {artist}: use this if the song name comes first.
  4. Custom separator: use this if you separate the two parts with something else, such as ::.
