What this site does

StudyBase provides GCSE and A-Level revision resources, past-paper discovery, subject pages, blogs, flashcards, focus tools, wellbeing support pages, account settings, resource viewers, protected access checks, and support/report flows.

Some pages run fully in the browser. Others talk to StudyBase API workers for account state, login, approved-email checks, protected-resource access, resource listings, reports, safety checks, and update checks.

Worker and service notes

  • Main API base: api.studybase.site.
  • Resource endpoints handle lists, access state, public resource data, and protected material retrieval.
  • Account endpoints handle session state, account profile, approved-email checks, and device/session safety.
  • Consent and analytics may use Google services; anti-abuse checks may use configured verification services.

UK legal scope

The StudyBase legal pages are intended to be read under the laws of England and Wales, with UK data protection matters handled by reference to UK GDPR, the Data Protection Act 2018, PECR where relevant, and any mandatory rights that cannot lawfully be excluded.
